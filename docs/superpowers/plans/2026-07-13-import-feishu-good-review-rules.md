# 飞书好评回复规则库导入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有飞书多维表格“评论回复”中新建“好评回复规则库”，导入最新版 Excel 的 13 个关键词分类，同时保持旧表和源文件不变。

**Architecture:** 使用当前已登录的飞书浏览器会话，通过多维表格的新建/导入功能把 Excel 作为一张独立新表导入。导入前后分别检查表名、字段、记录数和代表性内容；发生异常时先检查是否已产生部分新表，避免重复导入或覆盖旧表。

**Tech Stack:** 飞书多维表格网页、Playwright CLI（headed browser）、`G:/桌面/天猫评论回复/好评回复话术（新）.xlsx`

---

**Files:**

- Reference: `G:/桌面/天猫评论回复/docs/superpowers/specs/2026-07-13-feishu-good-review-rules-design.md`

- [ ] **Step 2: 核对源字段和内容计数**

核对表头严格为：`关键词分类`、`包含关键词`、`回复话术 1`、`回复话术 2`、`回复话术 3`；确认 13 个分类名称唯一，每个分类 3 条非空话术，总计 39 条。

Expected: 全部通过；如不通过则停止导入并报告源文件问题。

- [ ] **Step 3: 确认飞书登录状态与目标文档**

使用命名会话 `feishu-review` 读取页面快照，确认页面标题为“评论回复 - 飞书云文档”，且能看到现有表列表。

Expected: 已登录并可访问目标多维表格。

- [ ] **Step 4: 检查目标表名是否已存在**

保存导入前的飞书表清单，并记录每张旧表当前可见的记录数；在表列表中查找“好评回复规则库”。

Expected: 不存在；如已存在则停止，不覆盖、不创建同名表，并报告现状。

### Task 2: 创建并导入新表

**External changes:**
- Create: 飞书多维表格中的新表 `好评回复规则库`
- Preserve: 所有现有飞书表
- Preserve: `G:/桌面/天猫评论回复/好评回复话术（新）.xlsx`

- [ ] **Step 1: 打开新建表入口**

在当前多维表格内选择“新建”，使用“导入 Excel”或等价的新建表导入入口。

Expected: 导入向导打开，目标是当前多维表格中新建一张表，而不是新建另一个文档。

- [ ] **Step 2: 上传最新版 Excel**

上传 `G:/桌面/天猫评论回复/好评回复话术（新）.xlsx`，选择工作表“好评回复话术”，启用“首行为字段名”。

Expected: 预览显示 5 列、13 条数据记录。

- [ ] **Step 3: 确认导入为独立新表**

提交导入，等待完成。不得选择覆盖、追加或替换任何现有表。

Expected: 表列表出现一张由导入生成的新表。

如果导入命令中断、页面刷新或结果不明确，先重新读取表清单并与导入前清单比较：

- 恰好出现一张新表且有 13 条记录：继续验证并重命名；
- 恰好出现一张新表但记录数不是 13：停止，不删除、不覆盖、不再次导入，报告部分导入状态；
- 出现两张及以上新表：停止，不做进一步修改，报告重复/异常状态；
- 没有新表：确认导入确实失败后才允许重试一次。

- [ ] **Step 4: 将新表重命名为目标名称**

将导入生成的表重命名为 `好评回复规则库`。

Expected: 名称唯一，旧“好评话术”等表名和内容不变。

Expected: 65 个单元格全部一致，其中“回复话术 1～3”共 39 个非空值；不存在错位、截断、替换或附加空行。临时导出文件仅用于验证，不作为交付物。

Expected: 截图清晰可辨，旧表未被修改。
