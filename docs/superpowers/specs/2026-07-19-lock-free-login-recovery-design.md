# 无启动锁与登录自动恢复设计

## 目标

点击“立即处理一轮”后直接进入淘宝流程。已保存账号密码时自动登录；只有短信、验证码、滑块等淘宝人工验证才暂停。任何临时错误只结束当前尝试，不阻塞下一次点击。

## 设计

- 删除启动器 `Local\TmallReviewConsoleLauncher` 和服务端 `Local\TmallReviewConsole` 两层 Windows 命名互斥锁。
- 启动器只检查 `127.0.0.1:4300`：已有健康服务就打开控制台；没有就启动服务。并发启动由端口占用自然裁决，不再启动 PowerShell 锁辅助进程。
- 淘宝凭据读取发生瞬时错误时有限重试；读取不到凭据时给出明确配置提示，不再进入笼统“系统暂时无法完成操作”。
- 有凭据时由浏览器打开淘宝首页、自动填写并登录；遇到短信/验证码/滑块返回人工验证状态，用户完成后继续。
- 当前运行仍使用启动时取得的日期范围快照，界面只说明“当前运行使用此范围；修改下次生效”，不再出现“锁定”。

## 验证

- 服务端不再创建 Windows 互斥锁辅助进程。
- 启动器无 Mutex 代码，现有健康服务可直接复用。
- 凭据读取第一次失败、第二次成功时仍会打开淘宝并继续。
- 凭据持续不可读时显示明确可重试信息，下一次手动运行可重新开始。
- 真实 Chrome 本地流程通过后由用户实际点击确认；用户确认前不打包。
