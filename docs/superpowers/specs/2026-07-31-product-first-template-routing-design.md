# 商品优先话术分类设计

## 目标

评论分类必须先依据商品标题识别产品族，再在该产品族的专属分类中匹配评论语义；只有没有语义合格的专属分类时，才允许使用产品中立的通用分类或最终兜底分类。

## 已确认问题

真实评价商品为“漫步者 MF1 无线领夹小蜜蜂扩音器”，评论同时描述蓝牙频繁断连和有线模式音频延迟。现有流程把 DeepSeek 返回的有效分类“连接有延迟”直接保留，商品信息只参与兼容性和少量加分，没有形成优先候选层，因此最终使用了通用连接话术。

## 方案比较

1. **商品族候选分层（采用）**：识别耳机、音箱、扩音器、麦克风等商品族；若专属分类达到语义阈值，只在专属分类中选择。行为确定、可测试，并继续支持飞书维护的新分类。
2. **仅提高商品词权重**：保留所有分类竞争，给专属分类额外加分。改动小，但通用分类仍可能因同时覆盖多个词而胜出，不能保证商品优先。
3. **完全交给模型重选**：在提示词中强调商品。更灵活，但网络和模型波动会重复产生本次问题。

## 分类流程

1. 情感判断继续决定好评库或差评库。
2. 从商品标题和商品别名识别产品族。扩音器别名包括扩音器、喊话器、小蜜蜂、扩音喇叭等。
3. 对当前话术库所有分类计算现有语义分数和商品兼容性。
4. 将分类拆成两层：
   - 产品专属：分类、一级分类或关键词明确提到当前产品族。
   - 产品中立：不绑定产品族，但描述通用问题。
5. 只要存在达到最低语义阈值的产品专属分类，就从专属层选最高分，并允许它覆盖模型返回的产品中立分类。
6. 专属层没有语义合格项时，保留现有产品中立分类逻辑；仍无匹配时使用好评或差评通用兜底。
7. 同分时不武断跨分类：模型原分类属于最高分候选则保留，否则使用现有安全兜底，避免随机误选。

## 真实回归样例

- 商品：漫步者 MF1 无线领夹小蜜蜂扩音器。
- 评论：蓝牙频繁断连；切换有线耳麦后连接稳定但音频延迟明显。
- 模型原分类：连接有延迟（产品中立）。
- 预期：覆盖为语义合格的扩音器专属分类，不再落到产品中立的“连接有延迟”。

## 边界与安全

- 不因为商品是扩音器就随便选择任意扩音器话术；专属分类仍必须达到语义阈值。
- 如果扩音器专属分类只有续航、包装等无关问题，评论却只谈客服，则继续选择客服通用分类。
- 商品标题无法识别产品族时保持现有逻辑。
- 不修改模板正文、不生成库外承诺；最终回复仍来自已同步的话术模板。

## 验证

- 单元测试复现 MF1 真实评价并证明通用分类被产品专属分类覆盖。
- 单元测试证明无相关专属分类时仍可选择通用分类。
