# Windows 一键启动与真实验收设计

## 目标

交付一个双击即可启动的 `天猫评论助手.exe`。启动器负责拉起本地服务、打开控制台、维持“应用已打开”生命周期，并在用户从托盘退出时正常关闭服务。发布包不写入或回显淘宝密码、飞书密钥、DeepSeek 密钥。

## 方案

采用“原生 Windows 托盘启动器 + 随包 Node 运行时 + 同源静态控制台”。相比 Electron，该方案不引入第二套浏览器内核，也不会改变 `better-sqlite3` 与 Patchright 的 Node ABI；相比仅生成批处理文件，启动器没有命令行窗口，并提供明确的打开、退出和启动失败反馈。

发布目录包含：

- `天猫评论助手.exe`：自包含的 .NET 8 Windows 托盘程序。
- `runtime/node.exe`：固定的 Node 运行时。
- 服务端源码、PowerShell 受限助手、Web 生产构建和运行依赖。
- `data/`：本机运行数据目录。构建产物不复制浏览器登录资料；登录凭据继续只从 Windows 凭据管理器读取。

## 启动与退出

1. 启动器先探测 `http://127.0.0.1:4300/api/bootstrap`。
2. 已有健康实例时直接打开控制台，不重复启动服务。
3. 没有实例时，启动器用随包 Node 启动服务，设置同源 Web 路径并等待健康检查。
4. 健康后用默认浏览器打开 `http://127.0.0.1:4300/`，托盘保留“打开控制台”和“退出评论助手”。
5. 退出时关闭子进程标准输入，服务端完成当前安全边界内的收尾并释放单实例锁；超时才终止进程树。

## 静态 Web 与安全

Fastify 仅在显式提供 Web 构建目录时注册静态 GET 路由。路径必须落在构建目录内；不存在的带扩展名资源返回 404，前端路由回退到 `index.html`。API 仍保持原会话、CSRF 与回环地址限制。

发布脚本拒绝复制 `.env`、浏览器资料、SQLite WAL/SHM、日志、测试输出和源码仓库元数据。当前 SQLite 数据库只作为本机可选迁移项，不嵌入可分发包。

## 验收

- 单元测试覆盖静态文件、SPA 回退、路径穿越和 MIME。
- 启动器测试覆盖首次启动、已有实例、健康超时、重复启动与托盘退出。
- 打包后从发布目录双击 EXE，确认页面打开、API 同源、数据库创建、进程退出。
- 真实淘宝只读验收覆盖会话复用、掉线登录分支、多个弹窗依次关闭、评价页、日期、三种处理范围、多页/实时新增算法、初评/追评回复与投诉入口；停在任何真实提交动作之前。
