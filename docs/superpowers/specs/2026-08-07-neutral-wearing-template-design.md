# 未明确佩戴结构时的中性话术设计

## 目标

当商品标题没有明确写出“入耳式”“半入耳”“耳夹式”“头戴式”等佩戴结构时，佩戴类差评统一使用现有“标题中未提及佩戴类型”分类中的中性话术，例如“调整佩戴角度”，不发送“更换耳塞”“贴合耳道”等需要结构证据的话术。

## 设计

1. 商品标题证据优先于模型猜测。模型返回的入耳式或半入耳式分类不能在标题没有对应证据时直接保留。
2. 如果话术库存在“标题中未提及佩戴类型”分类，确定性分类修正优先选择它；其回复仍由维护的模板库提供。
3. “半入耳”和“入耳式”在商品识别中分开处理：半入耳不再被当作可更换耳塞的入耳式证据。
4. 如果未明确结构且没有中性分类，回复选择层过滤耳塞、耳道、入耳深度等结构性建议，并继续使用可兼容的通用模板，不生成库外承诺。
5. 分类被确定性修正后，保存的分类理由必须与最终分类一致，不能把模型旧理由和新分类拼成矛盾文本。

## 验证样例

- “漫步者原子豆 ANC … 半入耳 …” + 佩戴不适：不得选择入耳式耳塞话术。
- “漫步者 Zero Air 真无线蓝牙耳机 …”标题没有结构词 + 耳朵疼/容易掉：选择“标题中未提及佩戴类型”并使用“调整佩戴角度”。
- “明确写入耳式/耳塞式”的商品 + 佩戴不适：允许选择入耳式耳塞话术。
