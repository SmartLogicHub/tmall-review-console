# 天猫平台状态核对与浏览器生命周期整体修复设计

## 背景

真实运行暴露出四条相互耦合的故障：天猫已显示“投诉成立”但本地仍为 `failed`；本地失败案件下一轮再次尝试投诉；单条投诉或回复页面异常把整轮升级为 `manual_action_required`；浏览器操作超时通过关闭整个上下文取消正在运行的 Locator，造成 `locator.all: Target page, context or browser has been closed`，随后下一次取页又自动启动 Chrome。

## 目标行为

1. 每条评价进入 AI 或投诉流程前，先在该评价的精确行范围内读取初评/追评各自的平台动作状态。
2. “投诉成立 / 投诉处理中 / 投诉记录”是平台终态或进行中证据，必须回写本地并建立防重复终态，不得再次投诉或回复。
3. 单条评价的投诉入口变化、提交前页面中断、平台已处理或控件无法识别只结束当前评价，不暂停整批。
4. 提交前失败可安全释放为以后重新扫描；提交点击后中断必须进入不确定状态并禁止自动重试。
5. 普通元素或页面操作超时不再通过关闭整个 Chrome 作为首选取消手段；若上下文确实终止，原始 Playwright 错误必须转换成稳定业务结果。
6. `paused / manual_action_required / stopping / error / disabled` 状态不得隐式重新启动 Chrome。只有明确的新运行、继续或登录复查才能启动。
7. 前端展示业务状态与中文错误，不显示 `locator.all`、`Target page`、`BrowserContext` 等底层字符串；连接中断时不得继续把缓存状态显示为实时运行。

## 平台状态模型

评价快照增加按阶段隔离的平台状态：

- `none`：没有平台处理证据；
- `complaint_record`：已有投诉评价/追评记录，结果未知；
- `under_review`：平台处理中；
- `upheld`：投诉成立；
- `rejected`：投诉未成立；
- `reply_record`：该阶段已回复或存在回复记录；
- `non_replyable`：超过期限或回复关闭。

状态必须从目标评价行及其紧邻追评行读取，不能使用整页文字，以免串到其他评价。初评与追评分别核对。

## 本地核对与幂等

平台证据优先于本地未完成状态。处理前执行一个原子核对：

- `upheld`：本地投诉转为 `upheld`，移除投诉锁并写入 `complaint_upheld` tombstone；
- `under_review / complaint_record`：本地转为不允许重提的已处理状态，写入投诉终态 tombstone；
- `rejected`：只有页面同时证明仍可回复时才把动作锁交给回复，否则标记 `not_actionable`；
- `reply_record`：写入回复已完成 tombstone并跳过；
- `none`：才允许进入 AI 分类与严格投诉核验。

历史 `internal / failed` 案件在没有点击检查点时必须先核对平台；平台无记录才允许重新分析。存在点击或提交不确定检查点的案件永不自动重提。

## 单条失败与整轮控制

单条可归因失败返回 `skip` 或可重扫结果，不返回 `manual_action_required`。只有店铺身份不一致、真实登录验证、验证码/扫码、筛选范围不可确认或动作锁损坏才暂停整轮。界面文案必须反映真实阶段。

## 浏览器生命周期

浏览器上下文引入关闭原因与重启许可。操作截止时间先产生稳定超时结果，再取消后台等待；不能让关闭上下文产生的 Locator 异常抢先成为用户结果。运行已暂停或结束时，任何 `#page()` 调用都不能隐式启动新上下文。关闭页面恢复只允许在仍处于活动运行、提交尚未点击且重试预算未使用时执行一次。

## 前端与诊断

后端只返回稳定错误码与中文说明。底层异常仅进入脱敏结构化日志，记录 operation key、浏览器 generation、关闭发起者、是否已点击提交；不得记录 Cookie、Key、账号、评论正文或订单内容。前端查询连续失败时显示“本地服务连接中断，状态无法确认”。

## 验收

- 本地 `failed`、平台“投诉成立”：同步、跳过、不打开投诉框、不暂停；
- 已有投诉记录：禁止重提并继续下一条；
- 新投诉候选：严格核验通过且开关启用时自动提交；
- 提交无反应且仍在投诉框：关闭精确投诉框、终态跳过；
- `locator.all` 期间上下文终止：不显示底层英文、不形成关闭重开循环；
- 暂停后不自动启动 Chrome；
- 初评/追评状态互不污染；
- 单条失败不阻断日期范围完整扫描；
- 已修复的 AI 正文分类、DeepSeek 绑定、多轮投诉核验、跨页扫描和会话心跳生命周期不得回退。
